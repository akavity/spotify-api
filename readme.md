#  Tests for api.spotify.com

## General info:

* Test 1. Start or resume playback.
* Test 2. Pause playback.
* Test 3. Skips to next track.
* Test 4. Skips to previous track.
* Test 5. Set playback volume.

* Test 8. Get artist's top tracks.
* Test 9. Get album.
* Test 10. Get album tracks.

* Maven

* REST Assured 5.3.1
* Gson 2.10.1
